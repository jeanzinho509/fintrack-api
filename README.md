# fintrack-api
A production-oriented financial management application designed to demonstrate modern backend engineering practices.

Planned stack:

Java 21 • Spring Boot • Spring Data JPA • Spring Security • PostgreSQL • Flyway • JWT • JUnit • Mockito • Docker • GitHub Actions

The project will include:

Authentication and authorization
Accounts and transactions
Categories and budgets
Monthly financial reports
Validation and exception handling
Unit and integration tests
API documentation
CI/CD
Cloud deployment
